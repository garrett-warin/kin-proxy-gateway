Kin browser
Built for the everyday web

      
Kin is a browser-style web workspace with tabs, local bookmarks, local history controls, customizable search, and an FCPS access gate.

      
ENGINEBonfire v1.5Kin's custom proxy runtime
SEARCHChoice of engineBing, Google, Brave, or DuckDuckGo
YOUR DATAStored on this deviceBookmarks, history, themes, and preferences are kept locally
ACCESSFCPS verifiedAccount access is handled through Kin's verification gate

      
About the engine
Bonfire v1.5 is Kin's custom web engine. It handles page rewriting, loading, navigation, cookies, and links while Kin provides the browser interface, tabs, search, bookmarks, history, and appearance controls. External links and popup requests are routed through Kin's own tab system so browsing stays inside the Kin interface.
