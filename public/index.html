Kin browser
Built for the everyday web

      
Kin is a browser-style web workspace with tabs, local bookmarks, local history controls, customizable search, and an FCPS access gate.

      
ENGINEBonfire v1.5Kin's custom web runtime
SEARCHChoice of engineBing, Google, Brave, or DuckDuckGo
YOUR DATAEncrypted on this deviceHistory is encrypted locally; bookmarks, themes, and preferences stay on this device
ACCESSFCPS verifiedAccount access is handled through Kin's verification gate

      
About the engine
Bonfire v1.5 is Kin's custom web engine. It handles page loading, navigation, cookies, and links while Kin provides the browser interface, tabs, search, bookmarks, history, and appearance controls. Kin does not upload browsing history; history is encrypted on this device.
